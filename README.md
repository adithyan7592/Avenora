# AVENORA Career & Edu Consultants

MERN website for AVENORA — career guidance, MNC placement assistance, and education support.

## Run locally

1. Install MongoDB locally (optional — the API still starts if Mongo is offline).
2. From the project root:

```bash
npm run install:all
npm run dev
```

- Frontend: http://localhost:5173
- API: http://localhost:5000

## Stack

- **MongoDB** — contact enquiries
- **Express** — `/api/content`, `/api/contact`
- **React + Vite + Tailwind**
- **Node.js**
